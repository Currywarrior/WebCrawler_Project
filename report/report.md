## 二、任務 1：讀取與爬取全部網址

**流程**：`crawler.py` 讀 `urls.csv` → 正規化網址（去掉 `si`、`utm_*`、`guccounter` 等追蹤參數）去重 → 依網域判斷是 YouTube 還是一般網頁 → 分別進入影片流程或網頁流程。

**抓取策略（`fetch.py`）**：先查 robots.txt，同一站點請求間隔 1 秒。一般用 requests 取靜態 HTML；遇到以下兩種狀況改用 Playwright 開 Chromium 真瀏覽器：

1. **SSL 憑證鏈不完整**：bip.gov.tw、觀音戶政所、文化部國家文化記憶庫（#6、#7、#28）的伺服器沒送中繼憑證，Python 驗證失敗但瀏覽器可正常開啟，改用瀏覽器取得，紀錄中註明原因。
2. **前端 JS 渲染（SPA）**：桃園觀光導覽網（#2、#11、#12、#18、#19）用 requests 只拿到不到 200 字的空殼，需執行 JavaScript 後內容才會出現。瀏覽器會分段捲動到底，讓延遲載入的圖片寫入真正網址。

**延伸探索**：每頁擷取全部 `<a href>`，標記「是否在正文內」與「是否與觀音主題相關」（以觀音、白沙岬、甘泉寺、藻礁、草漯等 29 個地名／主題詞比對連結文字與網址）。只追「相關」的連結，限制為深度 1、每個種子頁最多 3 條、全部最多 30 頁、站點範圍限同站或 wikipedia.org／gov.tw／culture.tw。

## 三、任務 2：正文擷取與雜訊清理

清理分三層（`extract.py`）：

1. **整類標籤刪除**：`script、style、nav、footer、aside、header、iframe、button、svg` 等直接刪除。例外是 `<form>`：ASP.NET 網站（戶政所、原住民族文獻）整頁包在一個 form 裡，若直接刪會把正文刪光，所以只拆外殼保留內容（這是第一輪實測時 #7、#31 抓到 0 字後找出的問題）。
2. **class／id 語意判斷**：把 class 與 id 拆成單字，含 share、ad、cookie、subscribe、popup、related、recommend、comment、sidebar、banner、navbox 等詞的區塊視為雜訊。為避免誤刪，若一個區塊包含全頁 40% 以上的段落文字就不刪（例如外層容器 class 帶 `has-sidebar`）。
3. **正文定位**：先用已知站點規則（維基 `.mw-parser-output`、Yahoo `.caas-body`、痞客邦 `#article-content-inner` 等），找不到時用通用選擇器（`article`、`[itemprop=articleBody]`、`main`），最後用文字密度評分：段落文字越多、連結文字比例越低的容器分數越高。

轉 Markdown 時保留標題層級、段落、條列、表格與文內圖片（圖片放在原文位置並附說明與來源網址）。再用規則刪掉「分享到、訂閱、上一篇、版權所有」等站務短句，遇到「延伸閱讀、相關文章、你可能也喜歡」等小標題就截斷。作者與日期從 `meta`、`article:published_time` 與 JSON-LD 取出，放在每篇文章開頭。

## 四、任務 3：圖片擷取與過濾

- **延遲載入**：依序讀取 `data-src、data-lazy-src、data-original、srcset`（取最大寬度）等屬性，`<noscript>` 裡的備援 `<img>` 也會還原；JS 站點另外用瀏覽器捲動觸發載入。
- **只取正文內圖片**：圖片候選只從定位到的正文容器中找，所以側欄、頁首 Logo、廣告區的圖片不會進入候選。
- **過濾規則**：網址或 class 含 logo、icon、avatar、banner、pixel、share、qrcode、doubleclick 等詞排除；標註尺寸小於 100x80 或實際尺寸短邊小於 150px 排除（追蹤像素、圖示）；長寬比大於 4 排除（橫幅 Banner）；每頁上限 15 張。
- **去重**：同頁以網址去重（含維基不同解析度縮圖）；跨頁以 SHA-1 加感知雜湊（pHash）比對，相同圖片不重複下載，在 `index.jsonl` 標記 `duplicate_of_existing` 並指向已存的檔案。
- **對應關係**：每張圖記錄 `file、caption、src_url、context`（圖片前一段正文），Markdown 中圖片放在原文位置。排除的圖片也逐張記錄在 `images_rejected`（網址與原因），共排除 725 張：同頁重複 323、超過每頁上限 218、標註尺寸過小 77、Logo／廣告規則 51、實際尺寸過小 43、下載失敗 12、橫幅 1。
- **沒有圖片的頁面**：page_007（戶政所沿革）、page_008（甘泉寺官網簡介）、page_016（大堀溪）、page_025（領海基點）、page_026（國家文化記憶庫）的正文內沒有可取得或適合保留的圖片，已在文章開頭寫明「圖片：0 張」，沒有拿其他圖片代替。

## 五、任務 4：影片文字與代表畫面

- **基本資料**：用 yt-dlp 的 `skip_download` 模式只讀中繼資料（標題、頻道、上傳日期、長度、觀看數、說明欄、標籤），不下載影片。
- **字幕**：用 youtube-transcript-api 取平台公開字幕，優先順序為人工字幕再自動字幕，語言優先 zh-TW、zh-Hant、zh。video_001 取得 zh-TW 人工字幕 1,002 段、video_002 取得 zh-Hant 人工字幕 9 段。整理成 Markdown 時，每約 45 秒或停頓超過 3 秒切一段，段首標時間戳 `[00:01:23]`；每一段原始字幕的時間戳完整保存在 `timestamps` 欄位。
- **無字幕影片**：video_003 平台停用字幕，本組沒有取得音訊使用授權，所以不下載音訊做語音辨識，在紀錄中寫明原因。
- **代表畫面**：原本嘗試用瀏覽器開官方嵌入播放器截圖，但無頭瀏覽器會被 YouTube 擋下（錯誤 153），為了不繞過平台限制，改用 YouTube 播放器本身公開提供的 storyboard 預覽圖（拖曳進度條時看到的縮圖，320x180）。挑選方法：影片切成 5 段，每段算每格的清晰度（Laplacian 變異數），該時間點字幕含燈塔、沙丘、藻礁、蓮花、甘泉寺、石門水庫等地名或文化詞就加分，並用色彩直方圖相關係數大於 0.95 排除跟已選畫面太像的格子，全黑轉場格也排除。每張圖檔名含時間點（例如 `video_001_frame_04_002530.jpg` 為 00:25:30），並附該時間前後的字幕。video_003 沒有字幕，5 張畫面的說明由組員看圖人工撰寫，並標註「人工判讀」。

| 欄位 | 說明 |
|---|---|
| `id` | page_001～page_028、video_001～video_003、ext_001 起 |
| `type` | webpage／video |

| `images` | 網頁：檔名、說明、來源網址、前一段文字；影片：畫面時間點、檔案、對應字幕或畫面描述 |

## 七、任務 6：整理與查證

**相似／重複文章**（`output/similar_pairs.csv`）：用字元 2～3-gram 的 TF-IDF 向量加餘弦相似度比對所有成功文章（中文不必先斷詞也能比）。相似度 0.6 以上判為高度相似，0.35～0.6 為主題相近。結果抓出 page_001 與 ext_022 相似度 1.0，兩者是同一篇維基「觀音區」（網址分別為 `/zh-tw/` 與 `/wiki/` 寫法，網址去重沒抓到，靠內容比對抓到）；ext_015 與 ext_016 為戶政所兩個共用版型的頁面（0.71）。

**主題分類**（`output/classification.csv`）：以作業舉例的四類為基礎，再參考《觀音地方學》編纂計畫的八大主題補兩類，共六類：自然景觀與生態、歷史文化與信仰、地方產業與能源、農業與飲食、觀光景點與休閒、海洋法制與當代議題。每類有一組關鍵詞，計算詞頻（標題權重乘 5），取最高分為主分類，分數達主分類一半以上的列為次分類。限制：這是規則式分類，綜合性頁面容易被少數高頻詞拉走，例如 page_001 觀音區總覽因蓮花、農業出現次數多而被歸為「農業與飲食」，正式使用時需人工複核。

**關鍵字**：jieba 的 TF-IDF 抽詞，先把觀音地名（白沙岬燈塔、觀新藻礁、草漯沙丘等 36 個）加入字典避免被切碎，並去掉 Markdown 符號、網址與停用詞，每篇取 5 個。

**來源查證**（`output/fact_check.json`，3 筆）：

| 編號 | 網站上的敘述 | 查證來源 | 結論 |
|---|---|---|---|
| FC01 | vocus 部落格（page_009）：甘泉寺「清乾隆年間（約西元1780年）創建」 | 觀音區戶政事務所歷史沿革（政府網站）、甘泉寺官網、維基百科皆記為清咸豐年間（維基明確寫咸豐十年，1860） | **與官方來源不符**。沒有任何官方或學術來源支持乾隆說法，不採用 |

## 八、現場展示方式

```powershell
# 老師指定 urls.csv 中的任意編號（例如第 5 筆網頁、第 26 筆影片）
.venv\Scripts\python crawler\crawler.py --only 5,26
# 老師臨時給任一新網址
.venv\Scripts\python crawler\crawler.py --url "<網址>"
```

執行後即時顯示「原始網址 → 取得方式 → 狀態」，結果寫入 `output/articles/`、`output/images/`、`output/videos/` 與 `index.jsonl`，可直接打開 Markdown 對照原網頁。注意：video_003 的人工畫面描述是爬取後另外補上的，若重新爬取該影片需再補一次。
